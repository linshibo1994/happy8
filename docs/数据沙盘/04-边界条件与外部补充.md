# 边界条件与外部补充

## 1. 术语边界

### 1.1 全局与八区

全局分析基于 1-80 全号码范围，可以跨八区边界计算。八区分析只在单个区内部计算，不跨区。

示例：

| 号码组 | 全局口径 | 八区口径 |
| --- | --- | --- |
| `[10,11]` | 两连 | 不算同一区两连 |
| `[9,10,11]` | 三连 | 一区两连 `[9,10]`，二区单号 `11` |
| `[21,22,23]` | 三连 | 三区三连 |

### 1.2 连号重叠

默认不展开重叠子组，按最大连续段展示。例如 `[10,11,12,13]` 展示为一组四连。

筛选命中按“至少 N 连”处理。例如用户筛选三连号时，四连号也会命中，因为四连包含至少一段三连结构。

### 1.3 隔号

隔号默认只指差值为 2 的号码对。差值为 3 或更大不属于隔号。

### 1.4 连号隔号

连号隔号默认指同一个号码组中同时出现差值 1 和差值 2。示例包括 `[10,11,13]` 和 `[10,12,13]`。

### 1.5 间隔期数

“隔多少期”默认指两次事件中间空出的开奖期数。事件出现在第 100 期和第 103 期时，空窗期数为 2。

## 2. 数据边界

1. 开奖号码必须是 1-80 的整数。
2. 每期开奖必须有 20 个号码。
3. 同一期号码应去重；若数据源返回重复号码，应进入异常数据处理。
4. 缺少开奖日期时，不能参与按日期范围筛选。
5. 缺少期号时，不能进入历史列表主表。
6. 历史数据不足 N 期时，用实际数据计算并提示用户。
7. 日期范围和最近 N 期组合时，先做日期范围过滤，再取最近 N 期。
8. 分析结果必须能追溯到具体期号和开奖号码。

## 3. 分页边界

1. `page` 小于 1 时按 1 处理或返回参数错误。
2. `page_size` 超出允许范围时返回参数错误。
3. 筛选条件变化后前端回到第 1 页。
4. 当前页超出总页数时，前端应回退到最后一页或提示无数据。
5. 后端必须返回筛选后的真实总数，不能只返回当前页数量。

## 4. 计算边界

1. 空数据时，所有统计结果为空，不生成规律总结。
2. 事件出现 0 次时，出现率为 0，间隔不可计算。
3. 事件出现 1 次时，出现率可计算，间隔不可计算。
4. 平均空窗只基于相邻事件间隔计算。
5. 当前遗漏基于窗口内最新一期到最近一次事件之间的空窗计算。
6. 八区统计只计算该区内实际出现的号码，不用理论概率填补。
7. 多个区同时选择时，结果表应展示每个命中组的区号，避免混淆。

## 5. 性能边界

1. 最近 30、50、100、200、500 期应快速返回。
2. 自定义期数需要设置上限，建议首版不超过 1000 期。
3. 规则计算应在后端服务层完成，避免前端下载大量全量历史后本地计算。
4. 高频重复查询可以按请求参数生成缓存键。
5. 图表只渲染当前页面必要数据，避免一次性渲染过多表格行。

## 6. 异常状态

| 场景 | 处理 |
| --- | --- |
| 后端接口失败 | 显示失败状态和重试按钮 |
| 同步最新开奖失败 | 保留最近成功数据并提示同步失败 |
| 无匹配期号 | 显示“未找到对应期号” |
| 无命中规则 | 显示“当前条件下未找到命中期号” |
| 样本不足 | 显示“样本不足，无法计算间隔” |
| 参数非法 | 显示具体字段错误 |
| 部分图表失败 | 保留其他表格和摘要，只在失败面板显示错误 |

## 7. 合规与表达边界

1. 数据沙盘只做历史数据统计和结构分析。
2. 规律总结不能承诺未来开奖结果。
3. 不使用“稳赚”“必出”“稳赚不赔”“稳定命中”等表述。
4. 不引导用户投注。
5. 摘要文案需要可追溯到具体数据和表格。
6. 样本不足时必须明确提示，不生成伪结论。

### 8.3 建议补充能力

这些能力不作为首版必须项，但适合作为数据沙盘后续增强：

1. 重号分析：本期与上一期重复号码数量。
2. 邻号分析：本期号码是否贴近上一期号码，例如上一期号码加减 1。
3. 同尾分析：相同个位数号码的分布。
4. 和值区间筛选：按和值低/中/高区间过滤历史期号。
5. 跨度区间筛选：按最大最小号码跨度过滤。
6. 质合比筛选：按质数/合数分布过滤。
7. 012路筛选：按除 3 余数分布过滤。
8. 周几分析：按开奖日维度查看结构分布。
9. 事件热力日历：按日期展示规则命中密度。
10. 保存视图：保存常用规则组合。
11. 导出筛选结果：CSV 或图片。
12. 对比基线：当前 100 期与最近 500 期或全量历史比较。

## 9. 待用户确认清单

1. 八区是否固定为每 10 个号码一区。
2. 四连号在三连/两连筛选中是否算命中。
3. 是否需要“展开重叠子组”的高级开关。
4. 隔号是否只做差值为 2，还是需要支持差值为 3、4 的“多隔”。
5. 连号隔号是否采用“差值只包含 1 和 2 且两者都出现”的定义。
6. “隔多少期”是否采用空窗期数作为主指标。
7. 日期范围和最近 N 期是否采用“先过滤再取最近 N 期”。
8. 外部补充指标中，哪些要进入首版范围。
