# 功能详细与数据口径

## 1. 基础数据口径

### 1.1 开奖记录

每条开奖记录至少包含：

| 字段 | 说明 |
| --- | --- |
| `issue` | 期号，唯一标识一期开奖 |
| `draw_date` | 开奖日期时间 |
| `numbers` | 20 个开奖号码，号码范围 1-80 |
| `sum_value` | 20 个号码和值 |
| `odd_count` / `even_count` | 奇偶数量 |
| `big_count` / `small_count` | 大小数量，默认 1-40 为小，41-80 为大 |
| `zone_distribution` | 区间分布，现有数据可能为四区，数据沙盘需要补充八区统计 |

### 1.2 八区定义

| 区号 | 号码范围 | 展示名 |
| --- | --- | --- |
| 1 | 1-10 | 一区 |
| 2 | 11-20 | 二区 |
| 3 | 21-30 | 三区 |
| 4 | 31-40 | 四区 |
| 5 | 41-50 | 五区 |
| 6 | 51-60 | 六区 |
| 7 | 61-70 | 七区 |
| 8 | 71-80 | 八区 |

现有前端看板已有四区统计，数据沙盘新增八区统计时不能直接替换四区，应在展示上明确“八码区”和“四分区”两个口径。

### 1.3 分析窗口

分析窗口由筛选条件共同决定：

1. 先按期号、日期范围、号码条件过滤候选开奖记录。
2. 再按开奖时间倒序取最近 N 期。
3. 规则分析、间隔分析和规律总结均基于最终窗口计算。
4. 如果可用数据少于 N 期，前端显示“实际统计 X 期”。

## 2. 历史开奖结果查询

### 2.1 列表字段

历史开奖表展示：

| 列 | 行为 |
| --- | --- |
| 期号 | 支持复制，后续可点击进入详情 |
| 开奖日期 | 支持日期范围过滤 |
| 开奖号码 | 使用 20 个紧凑号码球展示 |
| 和值 | 支持排序 |
| 奇偶比 | 展示如 `9:11` |
| 大小比 | 展示如 `8:12` |
| 八区分布 | 展示八区迷你条或数字标签 |
| 命中结构 | 在规则筛选场景下展示连号/隔号标签 |

### 2.2 分页

分页参数建议：

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `page` | 1 | 当前页 |
| `page_size` | 20 | 每页条数，可选 20、50、100 |
| `total` | - | 当前筛选条件下的真实记录总数 |
| `has_more` | - | 可选，用于移动端无限滚动 |

现有 `/lottery/history` 的 `total` 为当前页数量，不满足严格分页。后续实现需要增加真实总数计算。

## 3. 期号查询

期号查询分两种：

1. 精确查询：完整期号命中单期详情。
2. 模糊查询：部分期号返回匹配列表。

期号详情除基础开奖字段外，应展示该期结构标签：

1. 最长连号长度。
2. 全局连号组。
3. 八区连号组。
4. 隔号组。
5. 连号隔号复合组。

## 4. 连号规则

### 4.1 基础定义

将一期开奖号码去重并升序排序后，如果一组号码相邻差值连续为 1，则为连号。

| 等级 | 规则 | 示例 |
| --- | --- | --- |
| 两连号 | `[x, x+1]` | `[25,26]` |
| 三连号 | `[x, x+1, x+2]` | `[31,32,33]` |
| 四连号 | `[x, x+1, x+2, x+3]` | `[10,11,12,13]` |

### 4.2 筛选命中口径

建议采用“至少 N 连”作为筛选命中：

1. 选择两连号：包含两连、三连、四连及更长连续段的期号都命中。
2. 选择三连号：包含三连、四连及更长连续段的期号都命中。
3. 选择四连号：包含四连及更长连续段的期号命中。

这样更符合用户“找出最近 100 期中有三连号的期号”的直觉。

### 4.3 展示计数口径

展示上建议区分两个指标：

| 指标 | 说明 |
| --- | --- |
| 命中期数 | 至少出现一次所选等级连号的期数 |
| 连号组数 | 默认按最大连续段计数，例如 `[31,32,33]` 计 1 组三连 |

高级选项可增加“展开子组”：例如 `[10,11,12,13]` 可展开为三个两连窗口、两个三连窗口和一个四连窗口。默认不展开，避免组数膨胀。

### 4.4 全局与八区

全局连号允许跨八区边界，例如 `[10,11]` 是全局两连。

八区连号不允许跨区边界，例如 `[9,10,11]` 在八区口径下不能算三区连续段，只能在一区识别 `[9,10]`，`11` 属于二区单号。

## 5. 隔号规则

### 5.1 基础定义

隔号默认指同一期内两个号码差值为 2，即中间隔 1 个自然数。

| 类型 | 规则 | 示例 |
| --- | --- | --- |
| 隔号对 | `[x, x+2]` | `[3,5]`、`[10,12]` |
| 连续隔号链 | `[x, x+2, x+4]` | `[3,5,7]` |

本阶段必须支持隔号对，连续隔号链可作为扩展展示。

### 5.2 全局与八区

1. 全局隔号允许跨区，例如 `[9,11]` 可算全局隔号。
2. 八区隔号不跨区，例如 `[9,11]` 不属于同一区，不能算八区隔号。

## 6. 连号隔号复合规则

连号隔号指一个号码组内部同时存在差值 1 和差值 2。

### 6.1 默认支持结构

| 结构 | 差值序列 | 示例 | 标签 |
| --- | --- | --- | --- |
| 前连后隔 | `1,2` | `[10,11,13]` | 连后隔 |
| 前隔后连 | `2,1` | `[10,12,13]` | 隔后连 |
| 两段连号中隔一号 | `1,2,1` | `[10,11,13,14]` | 连隔连 |
| 隔号后接两连 | `2,1,1` | `[10,12,13,14]` | 隔连连 |
| 两连后接隔号 | `1,1,2` | `[10,11,12,14]` | 连连隔 |

### 6.2 筛选条件

连号隔号筛选至少包含：

1. 分析期数。
2. 全局或八区。
3. 区号。
4. 复合结构类型。
5. 号码组长度，默认 3 或 4。

## 7. 事件结果表

规则筛选后，下方结果表展示：

| 列 | 说明 |
| --- | --- |
| 期号 | 命中的开奖期号 |
| 开奖日期 | 对应日期 |
| 开奖号码 | 完整 20 个号码 |
| 事件类型 | 两连、三连、四连、隔号、连号隔号 |
| 分析口径 | 全局或八区 |
| 区号 | 八区模式下展示 |
| 命中号码组 | 展示所有命中组 |
| 最长结构 | 例如最长四连 |
| 组数 | 当前口径下命中组数量 |

## 8. 下一次出现间隔

### 8.1 事件序列

对某类事件生成按时间升序排列的出现序列：

```text
issue_1 -> issue_2 -> issue_3 -> ...
```

事件可以是：

1. 全局两连、三连、四连。
2. 八区两连、三连、四连。
3. 全局隔号、八区隔号。
4. 全局连号隔号、八区连号隔号。

### 8.2 间隔计算

默认主指标为“空窗期数”：

```text
空窗期数 = 下一次事件在窗口中的序号 - 本次事件在窗口中的序号 - 1
```

示例：事件出现在第 100 期和第 103 期，中间第 101、102 期没有出现，则空窗期数为 2。

辅助指标为“相邻事件距离”：

```text
相邻事件距离 = 空窗期数 + 1
```

同样示例中，相邻事件距离为 3。

### 8.3 展示指标

| 指标 | 说明 |
| --- | --- |
| 出现次数 | 窗口内事件出现期数 |
| 平均空窗 | 相邻事件空窗的平均值 |
| 中位空窗 | 空窗序列中位数 |
| 最短空窗 | 最小空窗 |
| 最长空窗 | 最大空窗 |
| 当前遗漏 | 最新一期到最近一次事件之间的空窗期数 |
| 最近一次出现 | 最近命中期号 |

事件出现少于 2 次时，平均空窗、中位空窗、最短空窗和最长空窗显示“样本不足”，不能显示为 0。

## 9. 连号分析规律总结

### 9.1 输入条件

1. 连号等级：两连、三连、四连。
2. 分析范围：最近 N 期。
3. 分析口径：全局或八区。
4. 区号：八区口径下可选一个或多个区。
5. 对比基线：可选最近 200 期、500 期或全量历史。

### 9.2 输出结构

规律总结返回结构建议：

| 字段 | 说明 |
| --- | --- |
| `sample_periods` | 实际参与统计期数 |
| `event_level` | 连号等级 |
| `hit_periods` | 命中期数 |
| `hit_rate` | 命中率 |
| `total_groups` | 总组数 |
| `avg_gap` | 平均空窗 |
| `median_gap` | 中位空窗 |
| `max_gap` | 最大空窗 |
| `current_missing` | 当前遗漏 |
| `top_zones` | 八区高频区 |
| `baseline_delta` | 相对基线偏离 |
| `summary_text` | 可追溯的中文摘要 |

### 9.3 文案原则

总结文案必须使用描述性表述：

1. 可以说“最近 100 期三连号出现 18 期，出现率 18%”。
2. 可以说“第三区出现率高于八区均值”。
3. 可以说“当前空窗已高于该窗口中位空窗”。
4. 不能说“下期必出三连号”。
5. 不能说“按此规律投注更稳”。

## 10. 接口能力草案

本节只描述需求，不代表立即开发。

| 接口 | 方法 | 用途 |
| --- | --- | --- |
| `/lottery/history` | GET | 历史开奖分页查询，需返回真实总数 |
| `/lottery/results/{issue}` | GET | 期号详情 |
| `/lottery/sandbox/filter` | POST | 数据沙盘规则筛选 |
| `/lottery/sandbox/intervals` | POST | 同类事件下一次出现间隔 |
| `/lottery/sandbox/summary` | POST | 连号分析规律总结 |

规则筛选请求体建议：

```json
{
  "periods": 100,
  "date_start": null,
  "date_end": null,
  "issue": null,
  "scope": "global",
  "zones": [1, 2],
  "event_type": "consecutive",
  "consecutive_level": 3,
  "composite_pattern": null,
  "page": 1,
  "page_size": 20
}
```

## 11. 测试样例要求

后续开发必须覆盖以下样例：

1. `[1,2]` 命中全局两连。
2. `[10,11,12,13]` 命中全局四连。
3. `[9,10,11]` 全局命中三连，八区只在一区命中两连。
4. `[21,22,23]` 命中三区三连。
5. `[1,3]` 命中隔号。
6. `[10,11,13]` 命中连号隔号。
7. 事件只出现 1 次时，间隔统计显示样本不足。
8. 最近 N 期大于历史数据量时，显示实际统计期数。
