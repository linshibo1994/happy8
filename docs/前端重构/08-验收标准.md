# 前端重构验收标准

## 1. 功能验收

| 模块 | 标准 |
| --- | --- |
| 首页工作台 | 能展示最新开奖、下期期号、剩余次数、近期表现和快捷预测 |
| 历史数据看板 | 能按期数、日期、号码筛选，并展示图表和表格 |
| 单算法预测 | 能选择算法、配置参数、执行预测、展示结果 |
| 批量预测 | 能选择多个算法，逐个展示执行状态和汇总结果 |
| 算法中心 | 能展示所有核心算法、权限、详情和统计 |
| 预测历史 | 能展示预测记录、实际开奖号码、命中数量和命中率 |
| 会员中心 | 能展示等级、权益、剩余次数、订单 |
| 系统状态 | 管理员能查看数据同步和算法诊断入口 |

## 2. 交互验收

- 所有按钮有 loading、disabled、success、error 状态。
- 预测执行期间不能重复提交。
- 批量预测每个算法有独立状态。
- 表格筛选后不出现页面跳动。
- 移动端参数配置使用抽屉或全屏表单。
- 所有空状态有明确下一步行动。

## 3. 视觉验收

- 色彩符合朱砂、深墨、玉白、青铜、数据蓝体系。
- 页面不出现廉价闪烁、满屏金色、杂乱背景。
- 号码球尺寸稳定，移动端不挤压。
- 图表 tooltip 不遮挡关键数据。
- 表格密度支持舒适和紧凑两档。
- 文本不溢出按钮、卡片、表格列。

## 4. 动效验收

- 页面进入动效不超过 300ms。
- 预测进度条必须包含阶段文字和百分比。
- 号码生成动效必须在 1 秒内完成。
- 命中复盘动效只触发一次。
- 动效在低性能设备上可降级。

## 5. 数据验收

- 最新开奖与后端接口一致。
- 历史表格字段完整。
- 统计图的筛选范围与表格一致。
- 预测结果中的算法、期号、分析期数、预测数量、耗时、置信度完整。
- 命中率计算展示不能把 `0%` 当作空值。

## 6. 性能验收

| 指标 | 标准 |
| --- | --- |
| 首屏关键内容 | 2 秒内可见 |
| 路由切换 | 300ms 内有反馈 |
| 表格 | 1000 行以内筛选不卡顿 |
| 图表 | 500 个点以内交互流畅 |
| 预测提交 | 100ms 内进入执行状态 |

## 7. 可访问性验收

- 关键按钮可键盘访问。
- 图表提供文本摘要。
- 颜色不能作为唯一信息来源。
- 命中与未命中同时使用颜色和形态区分。
- 深色和浅色主题下对比度可读。

## 8. 测试验收

必须覆盖：

- 首页加载。
- 最新开奖展示。
- 历史数据筛选。
- 单算法预测。
- 批量预测。
- 预测失败重试。
- 权限不足。
- 次数不足。
- 预测历史复盘。
- 移动端布局。

## 9. 上线前检查

- 无前端控制台错误。
- 无接口未处理错误。
- 无明显布局错位。
- 所有预测页都有理性使用提示。
- 支付和会员相关页面经过单独安全 Review。
