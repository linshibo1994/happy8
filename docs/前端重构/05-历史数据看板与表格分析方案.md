# 历史数据看板与表格分析方案

## 1. 看板目标

历史数据看板的目标是让用户快速回答五个问题：

1. 最近哪些号码更热？
2. 哪些号码遗漏较久？
3. 和值、奇偶、大小、区间是否有明显偏态？
4. 某个号码或号码组近期走势如何？
5. 我的预测和开奖之间的命中表现如何？

## 2. 指标体系

| 指标 | 说明 | 展示方式 |
| --- | --- | --- |
| 开奖期数 | 当前筛选范围内总期数 | 指标卡 |
| 平均和值 | 号码总和平均值 | 指标卡 + 趋势线 |
| 奇偶比 | 奇数与偶数分布 | 堆叠条形图 |
| 大小比 | 1-40 与 41-80 分布 | 堆叠条形图 |
| 区间分布 | 1-20、21-40、41-60、61-80 | 四象限条形图 |
| 热号 | 出现频率最高号码 | Top 表格 |
| 冷号 | 出现频率最低号码 | Top 表格 |
| 最大遗漏 | 连续未出现期数最高号码 | 排名表 |
| 号码共现 | 两个号码同期开奖次数 | 矩阵热力图 |

## 3. 图表清单

| 图表 | 数据 | 交互 |
| --- | --- | --- |
| 号码热力图 | 1-80 出现频率 | 点击号码进入走势详情 |
| 和值走势 | 每期和值 | 支持选择期数窗口 |
| 奇偶大小趋势 | 每期奇偶/大小数量 | 支持切换奇偶、大小 |
| 区间分布图 | 四区间数量 | 支持按期数聚合 |
| 遗漏曲线 | 号码遗漏变化 | 支持最多选择5个号码 |
| 共现矩阵 | 号码对出现次数 | 支持缩放和过滤 |
| 预测命中趋势 | 用户历史预测 | 支持按算法筛选 |

## 4. 表格设计

### 4.1 历史开奖表

| 字段 | 行为 |
| --- | --- |
| 期号 | 可搜索、可点击详情 |
| 开奖日期 | 支持日期范围筛选 |
| 开奖号码 | 使用紧凑号码球展示 |
| 和值 | 可排序 |
| 奇偶比 | 可排序 |
| 大小比 | 可排序 |
| 区间分布 | 使用迷你条形图 |

### 4.2 号码统计表

| 字段 | 行为 |
| --- | --- |
| 号码 | 固定列 |
| 出现次数 | 可排序 |
| 出现率 | 可排序 |
| 当前遗漏 | 可排序 |
| 最大遗漏 | 可排序 |
| 最近出现期号 | 可点击 |
| 区间 | 可筛选 |

### 4.3 预测复盘表

| 字段 | 行为 |
| --- | --- |
| 预测时间 | 可排序 |
| 目标期号 | 可点击 |
| 算法 | 可筛选 |
| 预测号码 | 命中号码高亮 |
| 实际号码 | 命中号码高亮 |
| 命中数 | 可排序 |
| 置信度 | 可排序 |
| 耗时 | 可排序 |

## 5. 筛选系统

顶部筛选必须固定在看板上方。

| 筛选项 | 控件 |
| --- | --- |
| 日期范围 | 日期范围选择器 |
| 分析期数 | 分段控件：30、50、100、200、自定义 |
| 号码范围 | 多选号码球 |
| 区间 | 复选框 |
| 统计类型 | Tabs |
| 算法 | 下拉多选 |

## 6. 数据分析师视角的交互

- 表格必须支持复制当前行数据。
- 所有图表必须支持导出图片。
- 筛选条件应反映在 URL query 中，便于分享。
- 看板支持“保存视图”，记录用户常用筛选。
- 指标卡点击后应联动图表和表格。

## 7. 空状态与异常状态

| 状态 | 文案 |
| --- | --- |
| 无数据 | 当前筛选范围暂无开奖记录 |
| 加载中 | 正在读取历史开奖数据 |
| 同步中 | 正在同步最新期开奖 |
| 接口失败 | 数据获取失败，请稍后重试 |
| 权限不足 | 该分析视图需要升级会员 |
