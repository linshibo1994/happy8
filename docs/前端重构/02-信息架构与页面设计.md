# 信息架构与页面设计

## 1. 导航结构

建议采用桌面端侧边导航 + 移动端底部导航。

| 一级导航 | 二级页面 | 说明 |
| --- | --- | --- |
| 工作台 | 首页概览 | 高频入口，展示最新开奖、下期预测、近期表现 |
| 预测 | 单算法预测、批量预测、预测结果详情 | 核心操作区 |
| 数据 | 历史开奖、走势图、统计分析 | 数据分析区 |
| 算法 | 算法中心、算法详情、算法表现 | 算法理解与选择 |
| 历史 | 预测历史、命中复盘 | 结果追踪 |
| 会员 | 会员中心、订单记录 | 权益与支付 |
| 我的 | 个人资料、偏好设置 | 用户配置 |
| 系统 | 数据同步、算法诊断 | 管理员入口 |

## 2. 首页工作台

### 首屏布局

首屏不做大面积营销 Hero，直接进入可操作信息。

```text
顶部状态栏：品牌 / 当前用户 / 会员等级 / 剩余次数 / 数据更新时间

主工作区：
左侧：最新开奖卡 + 下期目标期号 + 一键预测
中部：推荐算法横向卡片 + 批量预测入口
右侧：今日预测次数 + 近期命中表现 + 系统状态

下方：
走势摘要 / 最近预测 / 热冷号摘要
```

### 关键组件

| 组件 | 内容 |
| --- | --- |
| 最新开奖条 | 期号、20个号码、开奖时间、和值、奇偶、大小 |
| 下期行动条 | 下期期号、默认算法、分析期数、预测个数、开始按钮 |
| 近期表现卡 | 近7天预测次数、命中次数、最高命中算法 |
| 热门算法卡 | 算法名称、权限、历史使用次数、平均耗时、成功率 |

## 3. 预测执行页

### 页面分区

```text
左侧参数面板：
目标期号 / 分析期数 / 预测个数 / 算法参数 / 会员权限

中间执行区：
算法选择 / 阶段进度 / 当前执行日志 / 结果号码

右侧复盘区：
算法说明 / 历史表现 / 最近同算法预测 / 风险提示
```

### 单算法预测流程

1. 选择算法。
2. 输入或自动带入目标期号。
3. 调整分析期数与预测个数。
4. 点击开始预测。
5. 显示阶段进度。
6. 展示结果号码和分析说明。
7. 提供保存、复制、查看详情、加入对比。

### 批量预测流程

1. 选择多个算法。
2. 前端检查剩余次数是否足够。
3. 调用批量预测接口。
4. 每个算法单独显示执行状态。
5. 汇总展示交集号码、高频候选、算法分歧。

## 4. 历史数据看板

### 页面布局

```text
顶部筛选：日期范围 / 期号 / 分析期数 / 号码选择 / 统计类型

指标栏：开奖期数 / 平均和值 / 热号Top / 冷号Top / 最大遗漏 / 区间偏态

图表区：
号码热力图 / 和值走势 / 奇偶大小趋势 / 区间分布 / 遗漏曲线

表格区：
历史开奖表 / 命中复盘表 / 号码明细表
```

## 5. 算法中心

### 算法卡片内容

- 算法名称和分类。
- 权限等级。
- 推荐使用场景。
- 数据要求。
- 平均耗时。
- 历史命中表现。
- 是否可用。

### 算法详情页

| 区块 | 内容 |
| --- | --- |
| 算法档案 | 原理、复杂度、数据要求、适合场景 |
| 参数面板 | 默认参数、可调参数、参数解释 |
| 历史表现 | 使用次数、命中分布、近期波动 |
| 执行入口 | 直接带入该算法进入预测页 |

## 6. 预测历史与复盘

### 列表字段

- 创建时间
- 目标期号
- 算法
- 预测号码
- 实际开奖号码
- 命中个数
- 命中率
- 置信度
- 执行耗时
- 是否缓存

### 详情页

详情页必须把预测结果和实际开奖并排展示，命中号码使用高亮，不命中号码保持低调。用户要一眼看出“哪些中了、中了几个、是哪个算法给的”。

## 7. 移动端适配

- 首页以单列卡片流为主，保留底部导航。
- 预测页参数面板改为底部抽屉。
- 图表默认展示摘要，复杂表格进入全屏模式。
- 批量预测结果使用可横滑算法卡。
