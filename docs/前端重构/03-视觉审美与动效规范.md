# 视觉审美与动效规范

## 1. 视觉方向

设计关键词：数据化、克制、准确、东方秩序、现代金融终端。

不采用廉价彩票站常见的高饱和大红大金堆叠，而是使用深墨、朱砂、玉白、青铜、数字蓝组成稳定体系。整体像“专业开奖数据指挥台”，而不是广告页。

## 2. 色彩系统

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 主色 朱砂红 | `#C9352B` | 行动、命中、高亮 |
| 深墨黑 | `#171A1F` | 主背景、标题 |
| 玉白 | `#F7F3EA` | 页面底色、卡片底 |
| 青铜金 | `#B88A3B` | 高级会员、重点徽标 |
| 数据蓝 | `#276EF1` | 链接、趋势、执行状态 |
| 松石绿 | `#2E8B6D` | 成功、稳定、正向表现 |
| 风险橙 | `#D9822B` | 警告、次数不足 |
| 灰阶 | `#6B7280` | 次要文本 |

## 3. 字体与排版

- 中文优先使用 `霞鹜文楷` 或 `Noto Serif SC` 作为标题字体候选，营造庄重感。
- 正文和数据使用 `Noto Sans SC`。
- 数字和表格使用 `DIN Alternate`、`JetBrains Mono` 或 `Roboto Mono`。
- 数据字号必须稳定，不随视口宽度缩放。
- 按钮和数字球文字不得溢出，移动端最长文本必须换行或收缩。

## 4. 号码球设计

| 状态 | 视觉 |
| --- | --- |
| 开奖号码 | 实心朱砂红，白色数字 |
| 预测号码 | 玉白底 + 朱砂描边 |
| 命中号码 | 朱砂红 + 青铜外环 + 微弱脉冲 |
| 未命中号码 | 灰白底 + 低对比文字 |
| 交集号码 | 数据蓝描边 + 点状背景纹理 |

号码球固定尺寸：

- 桌面端：`36px`
- 移动端：`32px`
- 表格内：`24px`

## 5. 动效原则

动效只用于解释状态，不做无意义装饰。

| 场景 | 动效 |
| --- | --- |
| 页面进入 | 内容按信息优先级 60ms 递进出现 |
| 最新开奖刷新 | 号码球从低透明度滑入，最终稳定落位 |
| 算法开始执行 | 参数面板收束，进度轨道点亮 |
| 阶段切换 | 进度节点推进，当前阶段文字替换 |
| 号码生成 | 数字短暂滚动后定格，避免老虎机式夸张效果 |
| 命中复盘 | 命中号码产生一次轻微脉冲 |
| 表格筛选 | 表格行淡入淡出，不跳动 |

## 6. 预测执行进度条

进度条采用“阶段轨道 + 百分比 + 当前任务”的复合结构。

| 阶段 | 进度 | 展示文案 |
| --- | --- | --- |
| 权限校验 | 0-10% | 校验会员权限与剩余次数 |
| 数据准备 | 10-25% | 读取最近 N 期开奖数据 |
| 特征分析 | 25-50% | 分析频率、遗漏、区间与结构 |
| 算法计算 | 50-80% | 执行当前算法模型 |
| 结果校验 | 80-95% | 去重、排序、生成置信度 |
| 完成输出 | 95-100% | 生成预测结果 |

批量预测时，每个算法有独立微进度条，顶部显示总进度。

## 7. 图表审美

- 图表底色保持干净，网格线使用低对比灰。
- 热力图使用朱砂红到玉白的连续色，不使用彩虹色。
- 趋势线最多同时展示 5 条，超过后进入筛选模式。
- Tooltip 使用紧凑表格，不使用大面积浮层。
- 所有图表必须提供空状态、加载状态和错误状态。

## 8. 禁止项

- 禁止满屏金色、闪烁文字、烟花特效。
- 禁止把预测结果包装成确定性中奖承诺。
- 禁止使用难以阅读的毛笔字作为正文。
- 禁止卡片套卡片造成层级混乱。
- 禁止图表使用无意义 3D 效果。
