# 数据库版本管理机制文档

## 概述

本项目使用Alembic作为数据库迁移工具，建立了完善的数据库版本管理机制，支持数据库结构的版本控制、自动迁移、备份恢复等功能。

## 核心组件

### 1. 数据库管理器 (db_manager.py)
- **DatabaseManager类**: 提供完整的数据库版本管理功能
- **功能特性**:
  - 数据库连接检查
  - 自动创建数据库
  - 迁移环境初始化
  - 创建/执行迁移
  - 版本升级/降级
  - 备份/恢复
  - 迁移验证

### 2. 初始化脚本 (init_db.py)
- **功能**: 一键初始化数据库和插入初始数据
- **包含内容**:
  - 默认会员套餐（免费、VIP、尊享）
  - 预测算法配置（7种算法）
  - 系统基础数据

### 3. 数据库管理脚本 (db.sh)
- **功能**: 提供便捷的命令行接口
- **支持命令**:
  ```bash
  ./db.sh setup          # 完整设置
  ./db.sh check           # 检查连接
  ./db.sh migrate "描述"   # 创建迁移
  ./db.sh upgrade         # 升级数据库
  ./db.sh backup          # 备份数据库
  ```

## 使用流程

### 首次设置
```bash
# 1. 完整设置（推荐）
./db.sh setup

# 或者分步执行
./db.sh deps            # 安装依赖
./db.sh init            # 初始化
python3 init_db.py      # 插入初始数据
```

### 日常维护
```bash
# 创建新迁移
./db.sh migrate "添加新字段"

# 升级数据库
./db.sh upgrade

# 查看当前版本
./db.sh current

# 查看迁移历史
./db.sh history
```

### 备份与恢复
```bash
# 备份数据库
./db.sh backup backup_20250101.sql

# 恢复数据库
./db.sh restore backup_20250101.sql
```

## 安全特性

### 1. 操作确认
- 危险操作（降级、恢复、重置）需要用户确认
- 重置操作需要输入"RESET"确认

### 2. 完整性检查
- 迁移文件验证
- 数据库连接检测
- 版本一致性检查

### 3. 错误处理
- 详细的错误日志记录
- 操作失败时的回滚机制
- 友好的错误提示

## 数据库版本管理最佳实践

### 1. 迁移命名规范
```bash
./db.sh migrate "添加用户表索引"
./db.sh migrate "修改会员价格字段"
./db.sh migrate "新增预测缓存表"
```

### 2. 版本控制策略
- 所有迁移文件纳入版本控制
- 不要手动修改已提交的迁移文件
- 使用描述性的迁移消息

### 3. 部署流程
```bash
# 生产环境部署前
./db.sh validate        # 验证迁移
./db.sh backup          # 备份当前数据
./db.sh upgrade         # 执行升级
```

## 监控与日志

### 1. 日志系统
- 所有数据库操作都有详细日志
- 日志文件：`logs/database.log`
- 支持不同级别的日志记录

### 2. 性能监控
- 迁移执行时间记录
- 数据库连接池监控
- 慢查询识别

## 故障排除

### 常见问题
1. **连接失败**: 检查数据库服务和配置
2. **迁移冲突**: 使用`./db.sh validate`检查
3. **权限问题**: 确保数据库用户有足够权限

### 紧急恢复
```bash
# 快速回滚到上一版本
./db.sh downgrade -1

# 完全重置（谨慎使用）
./db.sh reset
```

## 扩展功能

本数据库版本管理机制具有以下特点：
- **完整性**: 覆盖迁移的全生命周期
- **安全性**: 多重检查和确认机制
- **易用性**: 简单的命令行接口
- **可扩展性**: 支持多种数据库和环境
- **可维护性**: 完善的日志和监控
